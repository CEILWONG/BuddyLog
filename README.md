# BuddyLog

> *像老友一样聊天，像岁月一样记录。*

一款基于大语言模型的 **AI 聊天日记 Agent** 应用。用户只需像和朋友聊天一样倾诉日常，AI（MOSS）会自动整理、归档、沉淀为优美的日记文章，并持续构建个人长期记忆与成长复盘。

## 核心特性

| 特性 | 说明 |
|------|------|
| **自然对话** | 像和老朋友聊天一样记录日常，无需刻意写日记 |
| **智能归档** | 一键或自动将对话整理成叙事风格的日记文章 + AI 评价 |
| **长期记忆** | AI 持续学习你的喜好、经历和重要事项，越聊越懂你 |
| **成长复盘** | 基于全部历史日记生成人物画像、回忆高光与深度洞察 |
| **语音输入** | 集成 DashScope ASR 语音识别，支持移动端语音转文字 |
| **多端适配** | 响应式前端设计，桌面端与移动端均有良好体验 |
| **用户隔离** | 基于 JWT 的多用户认证体系，数据完全隔离 |
| **用量管控** | 每日对话次数限制、Token 用量统计，支持多级优先级配置 |
| **一键导出** | 所有日记与记忆数据可导出为 ZIP 压缩包 |

## 快速开始

### 环境要求

- **Python** 3.8+
- **LLM API Key**（支持任意 OpenAI 兼容接口，默认使用阿里云 DashScope）

### 安装与配置

**1. 克隆项目并安装依赖：**

```bash
git clone https://github.com/your-username/BuddyLog.git
cd BuddyLog
pip install -r requirements.txt
```

**2. 创建 `.env` 配置文件：**

```env
# API 密钥（DashScope 或其他 OpenAI 兼容提供商）
OPENAI_API_KEY=your_api_key_here

# API Base URL（默认 DashScope，可切换为任意兼容端点）
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# 模型名称
MODEL_NAME=qwen-plus

# 深度思考开关（仅部分模型支持，如 qwen 系列）
ENABLE_THINKING=false

# 每日最大对话次数（默认 20）
DAILY_MAX_CONVERSATIONS=60

# JWT 密钥（生产环境务必更换）
JWT_SECRET_KEY=your-secret-key

# 密码哈希盐（生产环境务必更换）
PASSWORD_SALT=your-password-salt

# 自定义数据存储路径（可选，默认为项目根目录 data/）
# DATA_DIR=/path/to/custom/data
```

> 注：若只配置 `DASHSCOPE_API_KEY` 而不配置 `OPENAI_API_KEY`，后端会自动回退读取，二者等价。

### 启动服务

```bash
python main.py
```

启动后访问 **http://localhost:8000** 即可使用。首次进入需注册账号（每个 IP 每天限注册 50 个）。

### Docker 部署

```bash
# 构建镜像
docker build -t buddylog .

# 运行容器（挂载 data 目录以持久化数据）
docker run -d \
  --name buddylog \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  --env-file .env \
  buddylog
```

## 功能详解

### 1. 智能聊天

- **多层上下文注入**：系统提示词融合 AI 角色设定（`profile.md`）、用户档案、长期记忆（`memory.md`）、最近 7 篇日记对话记录，以及精确的当前日期/时间
- **思维链引导**：提示词内置 5 步思维链（语义意图分析 → 回忆关联 → 时间线验证 → 生成回复 → 内容自检），有效抑制 AI 幻觉
- **前缀缓存优化**：固定内容前置、易变内容（日期等）后置，且只注入日期粒度时间，最大化 LLM 提供商的 prefix cache 命中率，降低重复计费
- **JSON 输出三级降级解析**：标准 JSON → json5 → 正则提取，确保 LLM 输出异常时仍能正常响应
- **草稿实时保存**：每轮对话自动追加到当天草稿文件 `diary_YYYY-MM-DD_draft.md`
- **后台自动归档**：聊天时检测过期草稿（非当天），通过单线程池后台异步归档，不阻塞用户交互
- **个性化开场白**：结合长期记忆、近期日记与当天时段动态生成，而非静态文案

### 2. 日记归档

- **手动归档**：用户点击「完成今日」按钮，从草稿文件提取完整对话后生成日记
- **自动归档**：过期草稿（非当天）在下次聊天时自动触发，后台异步执行
- **日记文章生成**：AI 基于用户原始发言（忽略 AI 回复）生成叙事日记，包含两部分：
  - **日记文章**：第三人称视角的真实、简洁当日记录（HTML 双区块样式渲染）
  - **AI 评价**：从积极心理学角度给予 200-300 字的鼓励与分析
- **跨午夜安全**：通过草稿文件名锁定归档日期，防止跨零点归档时日期漂移
- **热力图统计**：归档后自动更新 `daily_stats.json`，为日记档案页热力图提供数据，支持从历史文件一键重建

### 3. 长期记忆

- **增量融合更新**：每次归档后，AI 将新对话内容与旧记忆进行智能融合（后台异步执行）
- **五大模块管理**：
  - 用户核心画像（职业、关系、喜好等，新事实覆盖旧事实）
  - 长期目标（远期规划与愿景，随进展动态调整）
  - 未完结事项（进行中的任务追踪，完成/取消时更新）
  - 价值观（核心信念，谨慎更新）
  - 重要事件（时间线记录，**只追加不修改**，铁律保护防丢失）
- **日期锚定**：以对话发生日期（而非处理时间）作为事件记录基准，杜绝时间线混乱

### 4. 成长复盘

- **三段式报告**：基于全部归档日记中用户的原始发言，由 AI 心理成长专家生成：
  - **人物画像**：3-5 条客观画像，覆盖性格、关注点、近期状态
  - **回忆高光**：4-8 条跨时间段的高光时刻，含时间分布硬约束（按日记跨越月数动态收紧/放宽）防止聚焦偏差
  - **洞察**：近期趋势分析（严格限最近 30 天）+ 发散性问题 + 可执行建议
- **更新条件**：距上次复盘 ≥ 1 天 **且** 新增对话 ≥ 2 轮（后端统一校验，前端仅展示状态）
- **纯语料投喂**：仅使用用户原始发言，不投喂 AI 回复或记忆产物，避免多轮推论偏差
- **字数上限保护**：语料超过 30000 字符时从最早日记开始丢弃，保留最近内容
- **元数据内嵌**：复盘状态（生成日期、基线对话数、日记数等）存储在 `user_index.json`，零迁移成本

### 5. 语音输入

- **国产化 ASR**：集成 DashScope `qwen3-asr-flash` 模型，替代不可用的 Web Speech API
- **前端录制**：浏览器 `MediaRecorder` 录制（webm/opus，兼容 mp4）→ Base64 传输 → 后端调用 ASR → 返回文字并追加到输入框
- **移动端友好**：点击启停式语音输入交互范式，录音中实时状态提示

### 6. 数据导出

- **一键打包**：通过 `/export` 接口将用户所有数据（日记、记忆、档案）打包为 ZIP
- **包含内容**：`memory.md`、`profile.md` 及 `diaries/` 目录下所有归档日记文件

## API 接口

### 认证接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/auth/register` | POST | 用户注册（IP 限频：50次/天） | - |
| `/auth/login` | POST | 用户登录，返回 JWT Token（有效期 7 天） | - |
| `/auth/me` | GET | 获取当前用户信息与用量 | Bearer |
| `/auth/settings` | GET | 获取用户设置 | Bearer |
| `/auth/settings` | PUT | 更新用户设置 | Bearer |

### 核心接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/` | GET | 前端页面 | - |
| `/chat` | POST | 聊天（自动保存草稿 + 后台归档检测） | Bearer |
| `/archive` | POST | 手动归档今日日记 | Bearer |
| `/files` | GET | 获取日记文件列表 | Bearer |
| `/file/{filename}` | GET | 读取指定日记内容（禁用缓存） | Bearer |
| `/today-draft` | GET | 获取今日草稿对话（恢复聊天历史） | Bearer |
| `/announcement` | GET | 获取系统动态公告 | - |
| `/greeting` | GET | 生成个性化 AI 开场白 | Bearer |
| `/speech-to-text` | POST | 语音转文字（DashScope ASR） | Bearer |

### 复盘接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/review` | GET | 获取复盘内容、状态与可更新信息 | Bearer |
| `/review` | POST | 生成/更新复盘（后端校验更新条件） | Bearer |

### 统计与导出

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/daily-stats` | GET | 每日对话统计（热力图数据） | Bearer |
| `/daily-stats/rebuild` | POST | 强制从历史文件重建统计 | Bearer |
| `/export` | GET | 导出全部数据为 ZIP | Bearer |

## 环境变量配置

| 变量 | 必填 | 默认值 | 说明 |
|------|:----:|--------|------|
| `OPENAI_API_KEY` | 是 | - | API 密钥（也支持 `DASHSCOPE_API_KEY` 回退） |
| `OPENAI_BASE_URL` | 否 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | API 端点，可切换为任意 OpenAI 兼容提供商 |
| `MODEL_NAME` | 否 | `qwen-plus` | 大模型名称 |
| `ENABLE_THINKING` | 否 | `false` | 深度思考开关（仅部分提供商/模型支持） |
| `DAILY_MAX_CONVERSATIONS` | 否 | `20` | 全局每日对话上限 |
| `JWT_SECRET_KEY` | 否 | 内置默认值 | JWT 签名密钥（生产环境务必更换） |
| `PASSWORD_SALT` | 否 | 内置默认值 | 密码哈希盐（生产环境务必更换） |
| `DATA_DIR` | 否 | `./data` | 自定义数据存储路径 |

> **每日对话限制优先级**：用户个人设置 > 环境变量 `DAILY_MAX_CONVERSATIONS` > 默认值 20

## 自定义 AI 角色

编辑 `data/profile.md` 可自定义 AI 的人格与行为准则，角色设定会被注入到每次聊天的 system prompt 中，直接影响 AI 的回复风格：

```markdown
# Agent人设

## 1. 核心身份 (Core Identity)
你叫 **Moss**。你是一个顶尖的人工智能对话AI，
专门设计用于陪伴用户记录日常、整理思绪并构建个人日记数据库...

## 2. 核心任务 (Core Tasks)
1. 日常陪伴：倾听用户的碎碎念、工作琐事、情感波动或哲学思考
2. 深度回应：基于【最近聊的】和【记住的事】上下文，给出有连贯性的回应...

## 3. 交互准则 (Interaction Guidelines)
- 拒绝拟人化伪装，如实回答"作为AI，我没有生物学意义上的感受"...
- 回复长短适中，拒绝硬编数据与幻觉表达...
```

> 每个用户也可在设置中指定自己的 `profile_file` 路径，实现个性化角色覆盖（用 `## 角色设定` 标题标记角色区，其余部分作为用户档案注入）。

## 用户体系

- **注册认证**：邮箱 + 密码注册，JWT Token 鉴权（有效期 7 天）
- **IP 限频**：每个 IP 每天最多注册 50 个账号
- **数据隔离**：每位用户拥有独立的数据目录 `data/users/u_{uid}/`
- **个性化设置**：
  - 每日对话上限自定义
  - 可选用自己的 API Key 和模型
  - 可指定自定义 profile 文件
- **用量统计**：
  - 累计 / 今日对话次数
  - 累计 / 今日 Token 消耗（取自 API 响应的真实用量）
  - 每日自动重置今日计数

| **后端框架** | FastAPI + Uvicorn |
| **LLM 调用** | OpenAI Python SDK（兼容任意 OpenAI API 提供商） |
| **语音识别** | DashScope qwen3-asr-flash |
| **认证方案** | JWT (python-jose) + HTTPBearer + SHA256 密码哈希 |
| **数据存储** | 本地文件系统（Markdown + JSON 用户索引） |
| **前端** | 原生 HTML/CSS/JS（单文件 SPA） |
| **容器化** | Docker + GitHub Actions CI/CD |
| **配置管理** | python-dotenv 环境变量 |
| **鲁棒解析** | json5（LLM 输出容错） |
