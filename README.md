# BuddyLog

> *像老友一样聊天，像岁月一样记录。*

一款基于大语言模型的 **AI 聊天日记 Agent** 应用。用户只需像和朋友聊天一样倾诉日常，AI 会自动整理、归档、沉淀为优美的日记文章，并持续构建个人长期记忆与成长复盘。

## 核心特性

| 特性 | 说明 |
|------|------|
| **自然对话** | 像和老朋友聊天一样记录日常，无需刻意写日记 |
| **智能归档** | 一键或自动将对话整理成第一人称叙事风格的日记文章 |
| **长期记忆** | AI 持续学习你的喜好、经历和重要事项，越聊越懂你 |
| **成长复盘** | 基于全部历史日记生成人物画像、回忆高光与深度洞察 |
| **语音输入** | 集成 DashScope ASR 语音识别，支持移动端语音转文字 |
| **多端适配** | 响应式前端设计，桌面端与移动端均有良好体验 |
| **用户隔离** | 基于 JWT 的多用户认证体系，数据完全隔离 |
| **用量管控** | 每日对话次数限制、Token 用量统计，支持多级优先级配置 |
| **一键导出** | 所有日记与记忆数据可导出为 ZIP 压缩包 |

## 快速开始

### 环境要求

- **Python** 3.8+
- **LLM API Key**（支持任意 OpenAI 兼容接口，默认使用阿里云 DashScope）

### 安装与配置

**1. 克隆项目并安装依赖：**

```bash
git clone https://github.com/your-username/BuddyLog.git
cd BuddyLog
pip install -r requirements.txt
```

**2. 创建 `.env` 配置文件：**

```env
# API 密钥（DashScope 或其他 OpenAI 兼容提供商）
OPENAI_API_KEY=your_api_key_here

# API Base URL（默认 DashScope，可切换为任意兼容端点）
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# 模型名称
MODEL_NAME=qwen-plus

# 深度思考开关（仅部分模型支持，如 qwen 系列）
ENABLE_THINKING=false

# 每日最大对话次数（默认 20）
DAILY_MAX_CONVERSATIONS=60

# JWT 密钥（生产环境务必更换）
JWT_SECRET_KEY=your-secret-key

# 自定义数据存储路径（可选，默认为项目根目录 data/）
# DATA_DIR=/path/to/custom/data
```

### 启动服务

```bash
python main.py
```

启动后访问 **http://localhost:8000** 即可使用。

### Docker 部署

```bash
# 构建镜像
docker build -t buddylog .

# 运行容器（挂载 data 目录以持久化数据）
docker run -d \
  --name buddylog \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  --env-file .env \
  buddylog
```

## 功能详解

### 1. 智能聊天

- **多层上下文注入**：系统提示词融合 AI 角色设定（`profile.md`）、用户档案、长期记忆（`memory.md`）、最近 7 篇日记对话记录，以及精确的当前日期/时间
- **思维链引导**：提示词内置 5 步思维链（语义意图分析 → 回忆关联 → 时间线验证 → 生成回复 → 内容自检），有效抑制 AI 幻觉
- **JSON 输出鲁棒解析**：三级降级策略（标准 JSON → json5 → 正则提取），确保 LLM 输出异常时仍能正常响应
- **草稿实时保存**：每轮对话自动追加到当天草稿文件 `diary_YYYY-MM-DD_draft.md`
- **后台自动归档**：聊天时检测过期草稿（非当天），自动提交后台线程异步归档，不阻塞用户交互
- **个性化开场白**：基于长期记忆和近期日记动态生成，而非静态文案

### 2. 日记归档

- **手动归档**：用户点击「完成今日」按钮，从草稿文件提取完整对话后生成日记
- **自动归档**：过期草稿（非当天）在下次聊天时自动触发，后台异步执行
- **日记文章生成**：AI 以第三人称视角，基于用户原始发言生成叙事日记，包含两部分：
  - **日记文章**：真实、简洁的当日记录
  - **AI 评价**：从积极心理学角度给予 200-300 字的鼓励与分析
- **跨午夜安全**：通过草稿文件名锁定日期，防止跨零点归档时日期漂移
- **热力图统计**：归档后自动更新 `daily_stats.json`，为日记档案页热力图提供数据

### 3. 长期记忆

- **增量融合更新**：每次归档后，AI 将新对话内容与旧记忆进行智能融合
- **五大模块管理**：
  - 用户核心画像（职业、关系、喜好等）
  - 长期目标（远期规划与愿景）
  - 未完结事项（进行中的任务追踪）
  - 价值观（核心信念，谨慎更新）
  - 重要事件（时间线记录，**只追加不修改**，铁律保护）
- **日期锚定**：以对话发生日期（而非处理时间）作为事件记录基准，杜绝时间线混乱
- **后台异步执行**：记忆更新在后台线程完成，不影响前端归档响应速度

### 4. 成长复盘

- **三段式报告**：基于全部归档日记中用户的原始发言，由 AI 心理成长专家生成：
  - **人物画像**：3-5 条客观画像，覆盖性格、关注点、近期状态
  - **回忆高光**：4-8 条跨时间段的高光时刻，含时间分布硬约束防止聚焦偏差
  - **洞察**：近期趋势分析 + 发散性问题 + 可执行建议
- **更新条件**：距上次复盘 ≥ 1 天 **且** 新增对话 ≥ 2 轮
- **纯语料投喂**：仅使用用户原始发言，不投喂 AI 回复或记忆产物，避免多轮推论偏差
- **元数据内嵌**：复盘状态（生成日期、基线对话数等）存储在 `user_index.json` 中，零迁移成本

### 5. 语音输入

- **国产化 ASR**：集成 DashScope `qwen3-asr-flash` 模型，替代不可用的 Web Speech API
- **Base64 音频传输**：前端录制音频 → Base64 编码 → 后端调用 ASR 模型 → 返回文字
- **移动端友好**：支持点击启停式语音输入交互范式

### 6. 数据导出

- **一键打包**：通过 `/export` 接口将用户所有数据（日记、记忆、档案）打包为 ZIP
- **包含内容**：`memory.md`、`profile.md` 及 `diaries/` 目录下所有归档文件

## API 接口

### 认证接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/auth/register` | POST | 用户注册（IP 限频：50次/天） | - |
| `/auth/login` | POST | 用户登录，返回 JWT Token | - |
| `/auth/me` | GET | 获取当前用户信息 | Bearer |
| `/auth/settings` | GET | 获取用户设置 | Bearer |
| `/auth/settings` | PUT | 更新用户设置 | Bearer |

### 核心接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/` | GET | 前端页面 | - |
| `/chat` | POST | 聊天（自动保存草稿 + 后台归档检测） | Bearer |
| `/archive` | POST | 手动归档今日日记 | Bearer |
| `/files` | GET | 获取日记文件列表 | Bearer |
| `/file/{filename}` | GET | 读取指定日记内容（禁用缓存） | Bearer |
| `/today-draft` | GET | 获取今日草稿对话（恢复聊天历史） | Bearer |
| `/announcement` | GET | 获取系统动态公告 | - |
| `/greeting` | GET | 生成个性化 AI 开场白 | Bearer |

### 复盘接口

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/review` | GET | 获取复盘内容与状态 | Bearer |
| `/review` | POST | 生成/更新复盘（后端校验条件） | Bearer |

### 统计与导出

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|:----:|
| `/daily-stats` | GET | 每日对话统计（热力图数据） | Bearer |
| `/daily-stats/rebuild` | POST | 强制从历史文件重建统计 | Bearer |
| `/export` | GET | 导出全部数据为 ZIP | Bearer |
| `/speech-to-text` | POST | 语音转文字（DashScope ASR） | Bearer |

## 自定义 AI 角色

编辑 `data/profile.md` 可自定义 AI 的人格与行为准则：

```markdown
# Agent人设

## 1. 核心身份
你叫 **Moss**，一个温暖、幽默的老朋友...

## 2. 核心任务
1. 日常陪伴：倾听用户的碎碎念...
2. 深度回应：基于上下文给出有连贯性的回应...

## 3. 交互准则
- 回复长短适中...
- 拒绝拟人化伪装...
```

角色设定会被注入到每次聊天的 system prompt 中，直接影响 AI 的回复风格。

## 用户体系

- **注册认证**：邮箱 + 密码注册，JWT Token 鉴权（有效期 7 天）
- **IP 限频**：每个 IP 每天最多注册 50 个账号
- **数据隔离**：每位用户拥有独立的数据目录 `data/users/u_{uid}/`
- **个性化设置**：
  - 每日对话上限自定义
  - 可选用自己的 API Key 和模型
  - 可指定自定义 profile 文件
- **用量统计**：
  - 累计 / 今日对话次数
  - 累计 / 今日 Token 消耗
  - 每日自动重置今日计数

## 核心功能

### 1. 智能聊天
- 基于用户档案和长期记忆生成个性化回复
- 支持多轮对话上下文
- 对话内容自动保存到草稿

### 2. 日记归档
- 点击"完成今日"手动归档
- 自动将过期草稿归档（非当天）
- 生成第一人称叙事风格的日记文章

### 3. 长期记忆
- 每次归档后自动更新记忆
- 基于原始对话 + 日期上下文融合新旧信息
- 用于后续聊天的个性化回复

### 4. 文件管理
- **草稿文件**: `diary_YYYY-MM-DD_draft.md` - 当日对话记录
- **归档文件**: `diary_YYYY-MM-DD_N.md` - 完成的日记
- **系统文件**: `profile.md`, `memory.md` - 用户画像和记忆

## 数据流

```
用户对话 → 草稿文件（实时保存）
    ↓
点击"完成今日" → AI提取结构化摘要
    ↓
AI生成日记文章（基于原始对话）
    ↓
更新长期记忆（基于原始对话+日期）
    ↓
保存归档文件
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 前端页面 |
| `/chat` | POST | 聊天接口 |
| `/files` | GET | 获取文件列表 |
| `/file/{filename}` | GET | 读取文件内容 |
| `/archive` | POST | 手动归档 |

## 前端体验优化

- **输入动画** - 发送消息后显示 "..." 闪亮动画，提示正在准备回复
- **归档提示** - 点击"完成今日"显示"正在整理今日记录..."加载状态
- **实时反馈** - 每次对话后显示"Buddy 已记下~"提示
